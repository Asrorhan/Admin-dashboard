# Orders Management Dashboard

A responsive dashboard application built with React to manage customer orders, track metrics, and export data.

## Features

- **Order Management:** View, search, filter, add, and delete orders.
- **Data Persistence:** Uses `localStorage` to save order data in the browser.
- **Excel Export:** Export the current order list to an Excel spreadsheet (`.xlsx`).
- **Responsive Layout:** Works on desktop, tablet, and mobile devices.

## Tech Stack

- **Frontend:** React, Javascript, HTML5, CSS3
- **Libraries:** `xlsx` (SheetJS) for Excel generation
- **Build Tool:** Vite

## Setup

1. `npm install`
2. `npm run dev`
